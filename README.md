# LeetCode Solutions

Practice repo for learning DSA by solving problems together — not by watching lectures.

## How a session works
1. Pick the next problem in order (below).
2. Talk through the approach first — pattern, brute force, then the better idea.
3. Write the code in the problem folder, run the tests in `solution.py`.
4. Fill in `notes.md` after solving: approach in your own words, time/space complexity, what tripped you up.
5. Push with a commit like `solve: two-sum (hash map)`.

## Order (from the DSA starter guide — 8 stages)
- **Stage 1 — Hash Map:** Two Sum, Contains Duplicate, Valid Anagram, Group Anagrams, Top K Frequent Elements, Longest Consecutive Sequence — done
- **Stage 2 — Two Pointers / Sliding Window:** Longest Substring Without Repeating Characters done; more to come
- Also done along the way: Add Two Numbers (Linked List), Longest Palindromic Substring (Strings)
- Later stages follow the guide: Binary Search, Stack/Queue, Trees/Graphs, Heap/Backtracking/DP.

## Layout
Each problem lives in its own folder: `<topic>/<number>-<slug>/`
- `README.md` — problem statement, examples, constraints, hints (no solution)
- `solution.py` — function signature + runnable tests, solution to be filled in
- `notes.md` — approach + complexity, filled in after solving
